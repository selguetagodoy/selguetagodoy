## Investigar, conectar evidencia y comprender decisiones

Trabajo en la intersección entre **Estado, mercados y sociedad**, combinando experiencia institucional, análisis regulatorio, infraestructura digital y datos territoriales. He trabajado en **SUBTEL, el Senado de Chile y FOSIS**, y en consultoría estratégica de asuntos públicos.

Este GitHub reúne **investigaciones abiertas, aplicaciones interactivas y recursos reproducibles**. Los resultados públicos mantienen sus fuentes y límites metodológicos identificados; no se incluyen antecedentes confidenciales de clientes.
